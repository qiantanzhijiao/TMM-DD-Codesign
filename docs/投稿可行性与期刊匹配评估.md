## 三、数据强度：硬的与软的

**可以站得住的部分**

- 光学侧有外部绝对验证，不只是 `R+T≤1` 这类内部自洽；坡印廷因子的回归检验证明该修正不是形式改动。
- 梯度验证做到隔离路径 + 全链 + 容差扫描 + 伴随残差四层，且明确指出 45 倍光学–电学抵消是误差来源而非求解器容差。这一层次的自查在可微仿真方法论文里属于加分项。
- 物理验证、参数反演、网格收敛外推、等预算分析形成闭环，负结果（E2 6/7、E4 未达标、8D 弱可辨识）全部写进正文与结论。
- 全文数据由结果文件派生并自动核验，无手写数字；口径经 11-07 审计统一。

**审稿人最可能攻击的部分**

1. **合成验证 / inverse crime**：观测由同一正向模型生成，只能证明梯度正确、优化机制可用，不能证明从实测数据可辨识。论文已自陈，但自陈不等于消除缺陷。
2. **零实验、零第三方交叉验证**：无实测 J–V / EQE / 椭偏拟合，也无 SCAPS-1D 或别的 DD 代码对照。这是冲击一区/高影响力刊最致命的一条。
3. **物理模型理想化**：1D、等温稳态、理想选择性欧姆接触、Boltzmann 统计、单一 SRH 寿命，无辐射/Auger/表面复合、无离子迁移、无串并联电阻、吸收谱无显式带隙截断；AM1.5G 为 50 nm 粗表插值到 41 点。因此 `η=27.74%` 只能作合成示例，不能与实测或细致平衡极限比较——论文已明确写出，但期刊编辑仍可能认为器件数字「像效率主张」。
4. **数值与统计口径**：生产网格 1.52% 离散不确定度；稠密伴随 O(N³)；单起点、单目标、两种优化器、无噪声，不足以支撑泛化的效率主张。
5. **可复现性承诺偏弱**：Data availability 写的是「接收后公开到版本化仓库」，投稿时代码不随稿可见。对强调软件归档的期刊是硬伤。
6. **创新点的量级**：相对 ∂PV 补上相干多层光学、相对 TFSolver 补上载流子输运、相对 Sol(Di)²T 去掉代理——耦合是真的，但核心效率主张只有 3×（8D）与删失下界（E4-H），没有数量级加速的实证。

**综合判断**：证据链完整、自洽、诚实，足以支撑一篇**方法学 / 计算物理类**论文；不足以支撑一篇以「突破性方法 + 器件/材料发现」为卖点的**高影响力综合类**论文。两者差别不在写作质量，而在是否有外部数据或第三方代码验证。

## 四、能否支撑「高质量论文」

分两档说，避免含糊：

- **按当前稿件（不补实验）**：够得上中科院 2 区的专业方法刊与器件/能源刊，前提是选刊口径与「modelling kernel」定位对齐。稿件的严谨性、负结果透明度、数值可复现性在这个层次是明显优势。
- **补强后（SCAPS 交叉验证 + 至少一组实测 J–V/EQE 拟合 + 开源代码 + 多起点噪声基准）**：可以上探 1 区综合或子刊层次。但即使补强，`E4 ≥10×` 未达标这一事实仍在，不宜把「数量级加速」当卖点；更稳妥的新意是「首个无插值、无代理的相干光学—全耦合 DD 端到端可微内核 + 诚实的适用边界」。

> 概率区间均为基于 scope 契合度、稿件定位与常见审稿尺度的主观判断，不是期刊公布的录用率，也未计入编辑个人偏好与当年稿件积压。

## 七、推荐顺序

**首选：Computer Physics Communications。** 理由不是分区最高，而是 scope 最贴合：稿件本质是「可微数值内核的算法与实现验证」，CPC 明确接收此类论文并允许以合成但严格的数值实验论证方法有效性；E0/E1 的外部绝对验证、容差扫描、伴随残差恰好是 CPC 审稿人看重的内容。要做的前置动作是把 `tmm.py`/`dd.py`/`device.py` 与三套实验脚本整理为带开源许可、可独立运行、附 README 与算例的程序包，按 CPiP 归档（或至少在投稿时提供可访问仓库），并把 Data availability 从「接收后公开」改为「投稿即公开」。补上这一步，这刊的命中率会明显高于其余 2 区选项。

**最省事：Solar Energy。** 稿件已按 `elsarticle` 排好、参考文献与图表按该刊格式核对过、Introduction 里已引用该刊近作，切换到投稿几乎零成本。若近期有毕业、结题或考核的时间压力，这是最稳的一条路。

**次选：Optics Express。** 若愿意把引言与结果重心向「Poynting 一致的相干产生率 + 无插值耦合」倾斜，并引用 TFSolver 建立直接对话，可投 Energy and Environmental Optics Express 专版；代价是重排模板、APC，以及可能被质疑「光学新意不足」。

**保底：Scientific Reports（3 区）→ J. Comput. Electron.（4 区）。** 命中率高，但前者有 APC 与认可度问题，后者分区偏低。除非时间紧或已被前面几刊拒过一轮，不建议作为第一志愿。

**暂不建议：npj Computational Materials / PRX Energy 现状硬投。** 两刊的定位与稿件自陈的局限直接冲突，编辑初审阶段就可能被退回，白白损失 2–4 周。若确要冲，按第八节补强后再投，并重写摘要的价值主张（从「框架可微」转向「用该内核解决了某个具实验/第三方验证的具体器件问题」）。

## 八、下一步建议（按性价比排序）

| 优先级 | 动作 | 作用 | 预估 |
|---|---|---|---|
| 1 | 整理开源程序包（许可、README、环境、一键复现）并投稿即公开 | 直接决定 CPC 能不能投；对所有刊的 reproducibility 项加分 | 2–3 天 |

| 4 | 单因子控制实验：固定观测集与光滑参数化，只变 8D→16D | 让 E4-H 的 PASS 有因果解释，不再受「三因素同时变」质疑 | 约 20–30 min 机时 |
| 5 | 多起点 / 加噪声 / 增加无梯度基线；生产网格提至 N≥97 | 支撑泛化主张、消除 1.52% 离散不确定度 | 1–2 周 |
