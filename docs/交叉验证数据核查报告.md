## 4. 验收判据逐项判定

判据逐字保留第 2 版方案 §5，**未放宽任何一个数值**；`acceptance_verdict.json` 带 `criteria_fixed_before_data: true`。

| 项目 | 阈值 | 实测 | 判定 |
|---|---|---|---|
| 暗态 J–V | RMSE < 0.05 mA/cm² 或相对误差 < 5% | RMSE **0.001436** mA/cm²（共同区间 41 点） | **PASS** |
| 光照 Jsc | < 5% | **7.03%**（SCAPS 32.06 vs UniDD 29.95 mA/cm²） | **FAIL** |
| Voc | < 20 mV | SCAPS 曲线不穿零，**无法定义** | **FAIL**（不可比） |
| FF | < 5% | 无 Voc crossing，**无法定义** | **FAIL**（不可比） |
| EQE 形状 | RMSE < 0.05 | **0.09634**（20 点） | **FAIL** |
| G(z) 回读 | RMSE / mean(ref) < 2% | **0.0002369%**（72 点） | **PASS** |

**总体：2 PASS / 2 FAIL，`all_pass = false`。**

### 必须随数字一起报告的限定条件

- `SCAPSErrorLogFile.log`：暗态在 **0.82 V** 收敛失败截到 0.80 V；光照在 **1.08 V** 收敛失败截到 1.06 V。超出共同收敛区间不参与比较。
- SCAPS 光照 `.iv` 自报 `Voc = 6.800466 V (extrapolated)`；Jtot 在 0–1.06 V 从 32.06 升到 32.48 mA/cm²，几乎与偏压无关。这是 **flatband + 表面复合接触 + 本征单层** 与 UniDD **Dirichlet 载流子密度选择性接触** 在物理上不等价造成的，不是离散误差。
- 暗态 `mean_rel_pct = 212%` 是暗电流近零导致的数值假象，判据按预指定的绝对误差分支判定，未临时切换口径。
- EQE 差异来自光学模型与光谱采样不同；按预指定阈值判 FAIL，未因「只是形状对照」而放宽。
- G(z) 回读与导入剖面平均偏差 0.0029%（148 个 SCAPS 网格点 vs 73 个 UniDD 点），是本次对照中最扎实的正面证据，说明单位换算与插值正确。
