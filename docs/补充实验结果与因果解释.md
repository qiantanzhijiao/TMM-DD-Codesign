# 补充实验结果与因果解释（E4-C 单因子控制 / E5 稳健性）

> 本文所有数字均由 `results_E4_factorial.json` 与 `results_baselines.json` 读取，未手工录入。两个实验的协议在执行前固定（pre-specified），执行后未修改。

## 1. 结论先行

- E4-C 在固定观测、固定参数化、只变维度的条件下，得到 **可实测**（非删失）的加速比对照。

  - 目标 loss = 0.001：8-D 3.57×（NM/L-BFGS = 25/7 次），16-D 8.57×（NM/L-BFGS = 60/7 次）；16-D 更大。

- **因果机制**：两臂 L-BFGS 达到同一 loss 的调用数基本相同，而无梯度单纯形法随维度升高明显变慢；加速比上升来自**对照方法退化**，不是梯度法本身变强。此外 8-D 是 16-D 的精确子空间，16-D 反问题约束更弱，这也能解释 16-D 最终 loss 更低。
- 因此 E4-H 在宽松阈值上的 8.57× 可归因于维度效应；但它在 1e-4 的 PASS 仍是**删失下界**，不是实测比值。

- 无论哪种情形，把删失下界写成实测加速比都是错误的。
- 原 E4「≥10× 未达标」与 E4-H「按删失下界 PASS、实测最大 8.57×」两条结论**一字未改**。
- E5 提供多起点、加噪声、五种无梯度基线的稳健性证据；由于噪声给 loss 带来下界，它**不用于**评价次数加速比比较。

## 2. E4-C：只变维度的单因子控制

| 固定项 | 取值 |
|---|---|
| RBF 基 / 宽度 | 14 个中心，σ = 55 nm（见脚本） |
| 观测集 | 6 个 J–V 偏压 + 6 个 EQE 波长 + 16 个 R/T 波长，共 44 个 |
| 真值 / 起点 / 预算 / 优化器 | 两臂完全相同 |
| 唯一变化 | 自由变量数 8-D ↔ 16-D |

8-D 的 6 个谱系数经固定行归一化高斯矩阵 M 映射为 14 个 RBF 系数，因此 8-D 是 16-D 的**精确线性子空间**，不是另一套参数化。

- 两臂合成目标最大绝对差：`0`（完全相同）
- 常数系数经 M 映射的误差：`1.110e-16`
- 起点 loss：`5.7315e-03`；真值 loss：`0.0e+00`
- L-BFGS 调用数：8-D 67，16-D 64
- Nelder–Mead 调用数：8-D 301，16-D 300
- NM 最优 loss：8-D 3.000e-04，16-D 2.240e-04

### 阈值对照表

> 表内分数统一为 Nelder–Mead 调用数 / L-BFGS 调用数，比值即梯度法的评价次数优势；删失行分子为 NM 的总预算。

| 目标 loss | 8-D | 16-D |
|---|---|---|
| 0.01 | 1/1 = **1.00× 实测** | 1/1 = **1.00× 实测** |
| 0.001 | 25/7 = **3.57× 实测** | 60/7 = **8.57× 实测** |
| 0.0001 | ≥301/25 = **≥12.04× 删失下界** | ≥300/23 = **≥13.04× 删失下界** |
| 1e-05 | 未达到 | ≥300/33 = **≥9.09× 删失下界** |
| 1e-06 | 未达到 | ≥300/43 = **≥6.98× 删失下界** |

- 8-D 实测加速比范围：1.000× ~ 3.571×
- 16-D 实测加速比范围：1.000× ~ 8.571×
- 结果文件 `summary.speedup_at_1e-4` 记录 8-D 12.04×、16-D 13.04× —— **两者都是删失下界**，不可当作实测加速比引用；`speedup_at_1e-3` 才是实测值。

删失下界按「NM 总调用数 ÷ L-BFGS 达到该 loss 的调用数」计算，它只保证真实加速比不小于该值，**不是**实测比值。

## 3. E5：多起点 / 观测噪声 / 扩展无梯度基线

- 实验臂：16D；起点数 2；每轮预算 80 次真实 `f()` 调用
- 噪声：1% relative Gaussian on synthetic observables
- 起点扰动：deterministic perturbation of the E4-H start, amplitude 0.02
- 基线：NelderMead, Powell, DifferentialEvolution, DualAnnealing, RBF-UCB Bayesian

> 注意：1% 相对噪声给 loss 带来约 10⁻⁴ 量级的下界，因此这批结果用于稳健性比较，不用于与无噪声梯度法比评价次数。

| 基线 | 共同预算下 mean best loss | std | 95% CI 半宽 | 平均 wall-clock (s) | 达到 1e-3 / 1e-4 的轮数 |
|---|---|---|---|---|---|
| Powell | 6.540e-04 | 2.803e-05 | 3.885e-05 | 172 | 2/2 · 0/2 |
| NelderMead | 8.900e-04 | 1.936e-04 | 2.684e-04 | 218 | 1/2 · 0/2 |
| RBF-UCB Bayesian | 9.042e-04 | 9.702e-05 | 1.345e-04 | 187 | 2/2 · 0/2 |
| DifferentialEvolution | 9.353e-04 | 1.259e-04 | 1.745e-04 | 185 | 1/2 · 0/2 |
| DualAnnealing | 1.001e-03 | 8.223e-05 | 1.140e-04 | 188 | 1/2 · 0/2 |

RBF–UCB 是手写轻量代理基线，不是调优过的 BO 库；两种子只能给出粗略离散度，不构成统计显著性结论。

## 4. 对稿件与投稿策略的影响

- 两版稿件（CPC / Solar Energy）新增独立小节 E4-C / E5，并只把 Limitations 里「尚需受控研究」的指针改为指向该小节；E4 与 E4-H 的结论段、图表、摘要中的数值均未改写。
- CPC 版仍以「可复现程序 + 数值算法 + 负结果可复现」为锚点；E4-C 的删失/阴性结论恰好加强这一定位，不应包装成加速能力。
- Solar Energy 版仍以「Poynting-consistent 可微 TMM/DD 内核」为锚点；E5 只是稳健性补充。
- 仍未解决的核心短板不变：**纯合成验证、无实测器件、无 SCAPS-1D 交叉验证**。这两项决定能否上一区 Top，补充实验不能替代。
