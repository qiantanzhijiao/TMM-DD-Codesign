## 2. 研究定位

**目标**：构造一个同时保留「完整相干多层光学」与「自洽载流子输运」、且全程可微的
一维仿真内核，用于灵敏度分析、可辨识性研究与模型内联合优化。

**不主张**：实验标定、效率记录、与实测数据的一致性、与 SCAPS-1D 的交叉验证、
高维反演的数量级加速。所有验证数据均为合成数据（inverse crime），论文中已明示。

与已有工作的关系（引用均为真实文献，见论文参考文献表）：
- ∂PV（CPC 272, 108232, 2022）：DD 可微，但光学为 Beer–Lambert，无干涉；
- Sol(Di)²T（arXiv:2512.02904, 2025）：分级可微 / 神经代理数字孪生；
- TFSolver（Optics Express 33(25), 52061, 2025）：PyTorch 可微 4×4 矩阵法，
  仅光学，不含载流子输运；
- Byrnes（arXiv:1603.02720）：多层光学计算的基础推导。

## 3. 物理与数值模型

### 3.1 可微 TMM

- 前向递推中每层振幅写为 `r` 的仿射函数：`(a_j,b_j)=(a_j^A+a_j^B r, b_j^A+b_j^B r)`，
  `r=−b_{L−1}^A/b_{L−1}^B`；无分支、按波长向量化、可微。
- `R=|r|²`，`T=Re(ñ_{L−1}/ñ_0)|t|²`，**不 clamp**。
- 场强：
  `|E(z,λ)|²/|E₀|² = |a|²e^{−αz} + |b|²e^{+αz} + 2 Re[a b* e^{2 i k_r z}]`。
- 能量守恒（逐层积分，避免跨界面积分的不收敛）：
  `A_field = Σ_j ∫₀^{d_j} (n_{r,j}/n_0) α_j |E_j|²/|E₀|² dz = 1 − R − T`。
- 产生率在 DD 节点上**解析求值**，不引入光学网格到电学网格的插值。

### 3.2 可微 DD

- 未知量 `(ψ, wⁿ, wᵖ)` 对数密度变量，消除 `(ψ,φn,φp)` 的规范冗余；
- 指数分解的 Scharfetter–Gummel 电流，避免 10²⁴ m⁻³ 量级相减的 float64 抵消；
- Poisson + 电子/空穴连续性全耦合 Newton，行–列均衡、迭代精化、电位阻尼 cap 0.4 V；
- 收敛判据：`|F| < max(tol·qG_max, F_floor)` 或 `‖J⁻¹F‖∞ < ε_step` 且 `|F| < η·qG_max`；
- 梯度：隐函数定理 `∂L/∂θ = ∂L/∂θ|direct − λᵀ ∂F/∂θ`，
  `Jᵀλ = ∂L/∂x*`，自定义 `torch.autograd.Function`，单次转置 Jacobian 求解。

## 5. 未达标项的处理（不隐藏、不改写判据）

1. **E2 网格判据**：扩展至 N=121、145，`Jsc` 单调收敛
   （29.417 / 29.950 / 30.164 / 30.268 / 30.324）；观测阶 p=2.72，
   Richardson 外推 `Jsc(N→∞)=30.412 mA/cm²`。
   生产网格 N=73 相对外推值误差 **1.52%**，N=73→97 仅变化 0.71%。
   结论：原失败源于**最粗网格欠分辨**而非离散格式不一致；论文显式报告该不确定性。
2. **E4 ≥10× 判据**：`results_supplement.json` 将已记录的真实调用历史改写为
   删失比（censored ratio）与等预算损失对比；**不改变未通过结论**，
   论文明确写出「The pre-registered target … is not met, and we do not claim it」。
3. **E4-H 高维补充实验（独立预注册，2026-11-07）**：为检验「梯度优势随设计维度增长」
   这一假设，另行设计 16 维反演（厚度 + 14 个光滑高斯 RBF 谱系数 + SRH 寿命，
   R/T 观测加密至 16 波长）。除维度、谱参数化与观测数外，loss 定义、阈值阶梯、
   优化器超参、逐次 `f()` 计数与起点规则全部沿用 E4；双方预算同时放宽至
   L-BFGS 200 次 / NM 600 次。结果：L-BFGS 在 23 / 34 / 45 次达到
   1e-4 / 1e-5 / 1e-6，65 次后 loss = 1.40e-7；NM 600 次内未达 1e-4
   （最好 1.19e-4，仅略高于阈值）。按与原 E4 相同的删失规则给出下界
   26.1× / 17.6× / 13.3×，该补充设定下 ≥10× 判据成立（PASS）。
   **须如实说明**：达标依据为删失下界而非实测比值；双方均达到的阈值上实测最大
   仅 8.57×（1e-3，7 vs 60 次）。且维度、参数化、观测数三者同时改变，
   不能把改进单独归因于维度，仍需单因子控制实验。原 E4 未通过结论及正文措辞
   一字未改，新结果作为独立小节 `sec:e4h` 加入论文。

## 6. 已知局限

- 合成验证 / inverse crime；未做实验标定，未与 SCAPS-1D 或其他 DD 代码交叉验证；
- 一维、等温、稳态、理想选择性欧姆接触、Boltzmann 统计、单一 SRH 寿命；
  无辐射/Auger/表面/晶界复合、无离子迁移、无串并联电阻、吸收谱无显式带隙截断；
- 伴随采用稠密 `3(N−2)` 求解，N=73 可行但复杂度 O(N³)；二维需稀疏/无矩阵伴随；
- 全链厚度梯度存在 45 倍光学–电学贡献抵消，对有限差分舍入敏感；
- 8 维谱参数可辨识性弱；仅单起点、单目标、两种优化器、无噪声，不足以支持泛化效率主张。
