# 实测器件校准与验证：可执行方案

**编写日期**：2026-11-08
**目的**：补齐当前稿件最大的短板——全部结果均为合成数据（synthetic inverse crimes），没有实测器件、没有跨代码交叉验证。本方案给出从「制备一批器件」到「稿件可以合法声称 experimental validation」的最短可执行路径。
**边界**：本轮**没有**制备或测量任何器件，文中不含任何实测数据；以下为方案与判据，不是结果。

## 1. 为什么现在的合成验证不够

UniDD 的 E3 已经证明：只用 J–V 与 EQE 时，`(d, k)` 存在补偿简并（更薄但更 absorbing 的层给出几乎相同的电学可观测量），必须加入 R/T 光谱才能解除。E4-C 又证明加速比随维度上升主要来自无梯度单纯形法退化，而不是梯度法变强。这些结论都是**在同一个模型内部自洽**得到的——观测由 UniDD 自己生成，再用 UniDD 去反演，即所谓的 inverse crime。

真实器件会引入模型里没有的东西：界面复合、离子迁移、非理想接触、粗糙界面散射、厚度不均、光谱与温度的标定偏差、迟滞。**只有留出数据上的预测误差**才能说明这套可微内核对真实器件有没有用。

## 2. 器件与批次设计

### 2.1 器件体系

首选与稿件参考结构一致的 p-i-n 平面异质结：

```
glass / TCO / TiO2 (50 nm) / absorber (变厚度) / spiro-OMeTAD (150 nm) / metal
```

 absorber 用 MAPbI₃-like 钙钛矿（Eg ≈ 1.55 eV）。若实验室已有更稳定、表征更成熟的体系（如 CdTe、CIGS 或有机体系），可以直接换，但**必须重新测 n(λ)+ik(λ) 并把 Eg/μ/τ 作为待校准参数**，不能沿用稿件里的合成数值。

### 2.2 样品矩阵（最低要求）

| 维度 | 水平 | 数量 | 作用 |
|---|---|---|---|
| 吸收层厚度 `d_abs` | 例如 200 / 350 / 480 / 620 nm（≥3 档，含 480 nm 参考点） | ≥4 档 | 制造光学厚度差异，检验 TMM 干涉项的厚度梯度 |
| 每档器件数 | ≥3 个独立像素 | ≥12 个器件 | 估计器件间离散度，不要只报单个「最好器件」 |
| 批次 | ≥2 个独立制备批次 | 2 | 分离批次效应与模型误差 |
| 光照强度 | 1 sun + 0.1 / 0.5 sun（可选） | — | 检验复合模型与 Voc 的对数依赖 |
| 温度 | 300 K 为主，25 / 45 °C（可选） | — | 检验等温假设 |

**关键**：厚度档位必须跨越相干干涉显著的区域。稿件光学消融显示 480 nm 参考器件里相干与单通的 Jsc 只差 0.007%，但 120–200 nm 薄层下厚度梯度差可达 24–40%。如果只做 480 nm 一档，实测数据**无法区分**全相干 TMM 与 Beer–Lambert，等于白做。这是样品设计里最要紧的一条。

### 2.3 每一档必须留档的元数据

制备日期/批次、前驱体批号、旋涂/蒸镀参数、退火温度与时间、手套箱水氧值、封装方式、器件面积（含掩膜面积）、测量顺序、扫描方向、稳定时间、实验室温湿度。这些是后面做不确定度与异常值剔除的依据。

## 3. 表征项目与精度要求

| 量 | 方法 | 目标精度 | 与 UniDD 的接口 |
|---|---|---|---|
| 各层厚度 `d` | 台阶仪 / 轮廓仪；截面 SEM 交叉核对；椭偏拟合 | ±5 nm 或 ±2% | `θ` 中的 `d_abs`；用于检验厚度梯度 |
| 复折射率 `n(λ)+ik(λ)` | 光谱椭偏（350–800 nm，≥5 nm 步长），同批次同工艺的单独薄膜 | n ±0.02，k ±5% | TMM 的 `nk` 表；避免直接引用文献值 |
| 反射 / 透射谱 `R(λ), T(λ)` | 紫外–可见–近红外分光光度计 + 积分球 | ±1% abs | 与 E3 的 8 个 R/T 波长观测对齐，解除 `(d,k)` 简并 |
| 明暗 J–V | 源表 + AAA 级太阳模拟器，AM1.5G 100 mW/cm²，标准电池标定 | 电流 ±2%，电压 ±1 mV | 6 个偏压点（0, 0.4, 0.7, 0.9, 1.0, 1.06 V） |
| EQE / 光谱响应 | 单色仪 + 锁相 + 标准 Si/Ge 探测器，300–850 nm | ±2% rel | 6 个 EQE 波长（420–760 nm） |
| 稳态输出 / 最大功率点跟踪 | 至少 300 s | — | 判断迟滞与离子迁移是否破坏稳态假设 |
| 光强依赖 Voc / Jsc | 中性密度片 | — | 判断复合机制是否偏离单一 SRH |
| 稳态 PL / TRPL（可选但强烈建议） | 时间分辨荧光 | — | 独立估计 `τ`，用于交叉核对反演出的寿命 |

**标定链**：太阳模拟器用可溯源标准电池标定，单色仪用标准探测器标定，椭偏用标准片校验。所有标定证书编号写进 `metadata.txt`。没有标定链的 J–V/EQE 不能用于定量反演。

## 4. 数据划分、反演与验证（核心方法）

### 4.1 划分原则：杜绝 inverse crime

```
calibration set : 某一批次的 2 个厚度档（如 350、480 nm）的全部器件
hold-out set    : 另一批次的其余厚度档（如 200、620 nm）的全部器件
```

- **绝对不能**用同一条曲线既拟合又「验证」。
- 批次也要分开：如果 hold-out 与 calibration 来自同一次制备，批次效应会被误当成模型能力。
- 报告时给出 hold-out 的**逐器件**误差，不只给平均；给出最差器件。

### 4.2 待反演参数与固定量

| 参数 | 处理 | 理由 |
|---|---|---|
| `d_abs` | 待反演，但用台阶仪/截面 SEM 作**先验 + 独立核对** | 有独立测量可交叉验证，最能说明反演是否可信 |
| `k(λ)` 幅值 `k_amp` | 待反演（R/T 光谱解除简并后） | E3 的补偿简并主角 |
| `τ_n = τ_p` | 待反演 | 与 TRPL 独立估计值比对 |
| `μ_n, μ_p` | 固定为先验（来自文献或独立 Hall/SCLC 测量） | 与 `τ` 在稳态 J–V 中耦合强，同时反演不可辨识 |
| `n(λ)`、`Eg`、接触参数 | 固定为实测值 | 减少自由度，避免过拟合 |
| 界面复合、离子迁移 | **不在模型内**；作为残差来源显式讨论 | 若残差系统性偏大，说明物理模型不足，不是优化器问题 |

### 4.3 反演流程

1. 把实测 `R(λ), T(λ), J–V, EQE` 插值到 UniDD 的观测网格，按稿件 loss 做归一化：`L = ||y(θ) − y*||² / ||y*||²`。
2. 用 calibration set 做梯度反演（L-BFGS + IFT adjoint，即稿件 E3/E4 的同一套代码），记录收敛曲线与参数估计。
3. **不做任何针对 hold-out 的再调参**：把 calibration 得到的参数直接前向预测 hold-out 器件的 J–V / EQE / R / T。
4. 计算 hold-out 残差，并与「用 Beer–Lambert 光学替代 TMM」的消融模型对比。这一步是整篇论文最关键的新证据：如果全相干 TMM 在薄层上显著优于 Beer–Lambert，稿件的中心主张才算在真实数据上站住。
5. 做不确定度传播：把厚度 ±5 nm、椭偏 n/k 误差、光谱标定 ±1–2%、温度 ±1 K 作为输入扰动，Monte Carlo（≥200 次）给出参数置信区间与预测带。

### 4.4 验收判据（预指定，不是事后挑）

| 判据 | 阈值（建议） | 若不满足 |
|---|---|---|
| hold-out J–V 逐点相对误差 | < 8%（或 < 0.5 mA/cm²） | 检查接触边界与界面复合，不要调优化器 |
| hold-out Jsc / Voc / FF | < 5% / < 2% / < 5% | |
| EQE 形状 RMSE | < 0.08 | 查光谱归一与 `k(λ)` |
| 反演 `d_abs` vs 台阶仪 | < 8% | 说明 `(d,k)` 简并未解除或椭偏 n/k 有偏 |
| 反演 `τ` vs TRPL | 同一数量级，且差异可解释 | 说明复合模型过于简单 |
| 薄层上 TMM 优于 Beer–Lambert | 厚度梯度或 J–V 残差有统计显著改善 | 中心主张在实测上不成立，需如实报告 |
| 残差结构 | 无系统性厚度/波长趋势 | 有趋势 = 缺物理机制，须在 Limitations 写明 |

**任何一条不达标都如实写进论文**，不要回头调阈值。这与本项目一直坚持的「保留 E4 未达标结论」是同一条纪律。

## 5. 与 SCAPS-1D 交叉验证的关系

| | 实测器件验证 | SCAPS-1D 交叉验证 |
|---|---|---|
| 比对对象 | 模型 ↔ 物理世界 | 代码 ↔ 另一个代码 |
| 能回答 | 全相干光学与 IFT 梯度对真实器件有没有用 | DD 内核与接触边界是否实现正确 |
| 不能回答 | 数值实现是否有 bug | 光学模型是否符合真实器件 |
| 稿件价值 | 决定能否从「方法学/专业刊」往上一档走 | 增强可复现性，主要服务 CPC/方法学定位 |

两条都要做，且顺序上**建议先做 SCAPS**（几天的软件工作，能先排除 DD 实现错误），再做实测（数月的实验工作）。否则实测对不上时，分不清是数值 bug 还是物理模型缺失。

SCAPS 那一步的具体操作见 `soldiff/SCAPS1D交叉验证方案.md`；那边已备好参照数据、参数换算表、官方脚本模板和自动比对工具。

## 7. 论文表述边界（逐句约定）

**在实测数据产出并通过判据之前，只允许这样写：**
> All targets are synthetic inverse crimes; no experimental calibration or cross-code validation has been performed.

**完成 SCAPS 但未做实测时：**
> The drift–diffusion kernel was cross-checked against SCAPS-1D under matched dark and user-defined generation profiles (Section X); no experimental device calibration has been performed.

**完成实测且通过判据后，才可写：**
> Calibration on one batch and blind prediction on a second batch give hold-out errors of ...; the coherent optical model reduces the thin-film residual relative to Beer–Lambert by ...

**任何时候都不许写**：device prediction、efficiency record、experimental validation（未做时）、或与实测值"吻合良好"而无误差表与不确定度。

同时必须同步回填的位置（做完后一次性改，不要只追加新章节）：摘要、Introduction 的贡献列表、Section 3 的实验路线图、Table 1 caption、Limitations 的「four classes」、Conclusions、两版 cover letter 与 Highlights、Data availability（新增数据集的存放位置与许可）。

## 8. 合规与安全

- 器件制备涉及铅基钙钛矿、有机溶剂与手套箱操作，按所在单位化学品与废液管理规范执行，做好个人防护与废弃物处置。
- 本工作不涉及人体受试者、动物实验或临床数据，无需伦理审批；若后续引入外部合作单位的测量数据，需确认数据使用许可与署名约定。
- 原始数据、标定证书与处理脚本建议随稿件一并公开（仓库已有 MIT 许可与 `CITATION.cff`），并把数据集单独存 Zenodo 取 DOI。
- 不得为凑达标而剔除不利器件；剔除标准必须在看结果之前预指定并写进 `metadata.txt`。
